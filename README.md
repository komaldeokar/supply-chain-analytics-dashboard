# 📦 Supply Chain Analytics Dashboard – Power BI

## 📌 Project Overview
The Supply Chain Analytics Dashboard is a mini project developed using Microsoft Power BI to analyze supply chain data and present meaningful insights through interactive visualizations. It helps users understand supply chain performance and supports data-driven decision-making.

## 🎯 Project Objectives
- Analyze supply chain data and identify important trends.
- Monitor key supply chain performance indicators.
- Present data using interactive charts, graphs, and visualizations.
- Make supply chain information easier to understand.
- Support better inventory and operational decision-making.

## 🛠️ Tools & Technologies
- **Microsoft Power BI** – Dashboard development and data visualization
- **Power Query** – Data cleaning and transformation, if used
- **DAX** – Calculated measures, if used
- **CSV/Excel** – Data source, depending on the dataset used

## 📊 Dashboard Features
- Interactive dashboard visualizations.
- Supply chain data analysis.
- Key performance indicator (KPI) monitoring.
- Trend analysis and visual reporting.
- Insights to support business decisions.

## 📁 Project Files
- `MINI PROJECT SUPPLY CHAIN.pbix` – Power BI dashboard project file
- `dashboard-screenshot.png` – Dashboard preview, if included
- Dataset file – Source data, if permitted to share

## 🚀 How to Use
1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Open `MINI PROJECT SUPPLY CHAIN.pbix` in Power BI Desktop.
4. If prompted, configure the required data source.
5. Explore the dashboard and interact with the available visualizations.
